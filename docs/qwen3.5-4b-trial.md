# Qwen3.5-4B 试用结果

2026-11-03，Apple Silicon Mac，32 GB 内存，Ollama 0.31.1，Q4_K_M。模型文件约 3.42 GB；观察到加载时 GPU 内存约 3.7 GB。

先按 0.6B 的兼容接口、提示词、temperature 0.7、1536 token 上限测试，第一条逻辑链请求在 180 秒时超时，未获得输出。不能据此单独断定是模型或接口故障。

随后改用 Ollama 原生接口，明确 `think:false`、4096 上下文、640 token 输出上限；前两条提示词追加“简洁作答、不超过250字”。测试内容相同，但参数和输出长度限制不同，因此耗时不是严格等条件性能对比。三条均正常结束，没有达到输出上限。

| 样例 | 耗时 | 结果 |
| --- | --- | --- |
| 写作逻辑链 | 46.6 秒 | 保留部分同意、健康和社交限定，但未按要求用中文；凭空加入第一人称朋友经历，未标注为假设 |
| 口语纠错 | 49.2 秒 | 最终版本改对 dislikes→dislike、interrupts→interrupt、watch→watched，保留烹饪视频细节；分析中仍把参考的音量大当作用户已表达的内容，并有不必要改写 |
| 正确句子检查 | 14.9 秒 | 正确判断 I have lived here for five years. 无语法错误，没有误改 |

在这三条样例中，4B 的语法处理与立场保留好于先前 0.6B，但仍存在编造经历、混淆参考与用户答案、违背语言要求的问题。实际短输出速度约 4.8–6.6 token/s，不适合在这台机器上作为快速、无需复核的默认核对工具。这是少量样例观察，不是总体准确率结论。

本次测试未将本地模型设为插件默认。
