# Logo 与文档设计

Logo 保存于 `src/assets/logo.png`，已用于 README 和应用面板。使用内置 imagegen 工具生成，透明背景，书页与对话气泡结合，沿用界面的深绿和浅绿色。

最终生成提示词：

> Use case: logo-brand. Create one polished minimal app logo for English Desk Studio, a small desktop IELTS writing and speaking practice app. A single geometric mark cleverly combines an open book with a small speech bubble, incorporating an understated E shape through negative space. Deep forest teal #24675A and a restrained mint accent #A8C8B9. Strong simple silhouette legible at 32px, elegant rounded geometry, consistent thick forms, flat vector-like design, balanced square composition, generous transparent padding. No text, no wordmark, no letters outside the symbol, no gradients, no shadows, no 3D, no mockup, no additional objects. Genuine transparent background. Deliver one final symbol, not a contact sheet.

README 布局参考 [LocalSend](https://github.com/localsend/localsend) 的功能、下载和使用顺序，以及 [RustDesk](https://github.com/rustdesk/rustdesk) 的居中品牌区和章节导航。文案为本项目重新编写，界面图片为实际运行截图。
